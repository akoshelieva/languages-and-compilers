My understanding of the implementation:
The optimizer checks variables by their declarations. It is important when we have two variables named x
in different code blocks, because only the unused one should be removed. The code also removes assignments to 
unused variables.The optimization runs several times because removing one variable can make another unused.
In additional task solution, the code checks whether a function has side effects. For example, a call that only 
calculates a value can be removed,but calls that print, read input or change an object should stay.
